# Bundled fonts (used by translate-apply and the text renderers)

- NotoSans-Regular.ttf, NotoSans-Bold.ttf, NotoSansDevanagari-Regular.ttf, NotoSansArabic-Regular.ttf:
  Noto fonts, Copyright 2010-2020 Google LLC, SIL Open Font License 1.1 (OFL.txt). From Debian fonts-noto-core.
- DroidSansFallback.ttf: Droid Sans Fallback (Chinese, Japanese, Korean), Copyright 2006-2010 Google Corp.,
  Apache License 2.0. From Debian fonts-droid-fallback. Chosen over Noto Sans CJK because it is a TrueType
  (glyf) font the PDF writer can embed and it is 3.4 MB instead of about 60 MB for the CJK set.

Total about 4.9 MB of image growth.
